# Facundo NFC — Tarjeta digital

Landing personal pensada para abrirse desde un llavero NFC.

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño responsive.
- `script.js` — botón para guardar el contacto como `.vcf`.

## Publicación gratuita

La opción recomendada es GitHub Pages.

1. Crear un repositorio público llamado `facundo-nfc`.
2. Subir `index.html`, `style.css` y `script.js`.
3. En GitHub: Settings → Pages.
4. Elegir `Deploy from a branch`.
5. Seleccionar `main` y `/ (root)`.
6. GitHub generará una URL `https://USUARIO.github.io/facundo-nfc/`.

## NFC

Una vez publicada la URL, el llavero se programa con esa URL como registro URI.
